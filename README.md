# Midnight Princess

A dark VS Code theme with midnight blues, glass-slipper light and a touch of pink.

## Palette

| Role | Color |
| --- | --- |
| Editor background | `#101827` |
| UI accent, keywords, operators, tags | `#5b8fd9` |
| Functions, keys, attributes, types (italic) | `#a8d8f0` |
| Strings, numbers, active highlights | `#e8e5e1` |
| Rare accents (this, regex, enum members) | `#f0a8b8` |

## Install

Search for **Midnight Princess** in the Extensions view, or run:

```
code --install-extension thaisemanuele.midnight-princess
```
