# Midnight Princess

A dark VS Code theme with midnight blues, glass-slipper light and a touch of gold.

## Palette

| Role | Color |
| --- | --- |
| Editor background | `#051224` |
| Sidebar and panels | `#030b17` |
| Menus, inputs and widgets | `#0a2a59` |
| UI accent (selection, buttons, badges) | `#1e4f91` |
| Keywords, operators (control flow in italic) | `#6ea8ff` |
| Functions, keys, attributes | `#a8d8f0` |
| Types, classes (italic) | `#7ed3ff` |
| Strings | `#38c6f4` |
| Text | `#e8f6ff` |
| Comments | `#7f8bc4` |
| Tags, numbers | `#f9e6b2` |
| Rare accents (this, regex, enum members) | `#f4c76a` |

## Install

Search for **Midnight Princess** in the Extensions view, or run:

```
code --install-extension thaisemanuele.midnight-princess
```
