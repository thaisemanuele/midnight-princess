# Midnight Princess

A dark VS Code theme with midnight blues, glass-slipper light and a touch of pink.

## Palette

| Role | Color |
| --- | --- |
| Editor background | `#131a33` |
| Sidebar and panels | `#0e1428` |
| Text | `#d6e0f0` |
| UI accent | `#4f7fd0` |
| Keywords, operators, tags | `#7ea6f2` |
| Functions, keys, attributes | `#a9cdf0` |
| Strings, properties | `#f5b5c4` |
| Types, numbers | `#f3e9dc` |
| Rare accents (this, regex, enum members) | `#c3b5f0` |

## Install

Search for **Midnight Princess** in the Extensions view, or run:

```
code --install-extension thaisemanuele.midnight-princess
```
